# Social Media Strategy - Technical Content

## Overview
Comprehensive guides for posting technical content across multiple platforms, leveraging 140+ backend posts.

## Posting Schedule
- **Frequency**: 5 posts per week (Monday - Friday)
- **Time**: Consistent posting times per platform
- **Content**: Technical, architecture, implementation details

## Platform Guides

1. [LinkedIn](./linkedin-guide.md) - Professional, long-form, technical
2. [Twitter/X](./twitter-guide.md) - Quick insights, threads, technical tips
3. [Instagram](./instagram-guide.md) - Visual, carousel posts, code snippets
4. [Medium](./medium-guide.md) - Deep dives, tutorials, case studies
5. [Valete+](./valete-guide.md) - Brazilian tech community, Portuguese content
6. [Personal Website](./website-guide.md) - Complete technical portfolio, all details

## Content Strategy

### Content Sources
- 140+ backend posts (architecture, implementation, lessons learned)
- Technical decisions (ADRs)
- Implementation deep dives
- Lessons learned
- Advanced topics

### Content Distribution
- **LinkedIn**: Architecture posts, technical decisions, lessons learned
- **Twitter**: Quick insights, technical tips, thread series
- **Instagram**: Visual code snippets, architecture diagrams, carousel posts
- **Medium**: Full articles, tutorials, case studies
- **Substack**: Weekly newsletters, deep dives, comprehensive technical content
- **Valete+**: Portuguese content, Brazilian tech community focus
- **Website**: Complete technical documentation, all posts, detailed case studies

## Posting Calendar

### Weekly Schedule (Monday-Friday)

**Monday**: Architecture/Design
- LinkedIn: Architecture overview post
- Twitter: Architecture thread
- Instagram: Architecture diagram carousel
- Medium: Architecture deep dive (if publishing)

**Tuesday**: Technical Decisions
- LinkedIn: ADR explanation
- Twitter: Decision thread
- Instagram: Decision flowchart
- Medium: ADR full article (if publishing)

**Wednesday**: Implementation
- LinkedIn: Implementation deep dive
- Twitter: Implementation tips thread
- Instagram: Code snippet carousel
- Medium: Implementation tutorial (if publishing)

**Thursday**: Lessons Learned
- LinkedIn: Lessons learned post
- Twitter: Lessons thread
- Instagram: Lessons infographic
- Medium: Lessons learned article (if publishing)

**Friday**: Cross-Cutting/Advanced
- LinkedIn: Advanced topic or cross-cutting concern
- Twitter: Advanced topic thread
- Instagram: Advanced topic visual
- Medium: Advanced topic article (if publishing)

## Content Repurposing

### One Source, Multiple Formats
1. **Source**: Backend post (e.g., "Dead Letter Queues")
2. **LinkedIn**: Long-form post (500-800 words) with diagram
3. **Twitter**: 5-8 tweet thread with key points
4. **Instagram**: Carousel with code snippets and diagrams
5. **Substack**: Weekly newsletter (1500-3000 words) with comprehensive content
6. **Medium**: Full article (1000-2000 words) with code examples
7. **Valete+**: Portuguese version, community-focused
8. **Website**: Complete documentation with all details
