# Instagram Guide - Technical Content Strategy

## Platform Overview
Instagram is visual-first. Focus on code snippets, architecture diagrams, and carousel posts. Less text, more visuals.

## Positioning

### Personal Brand
- **Username**: @yourhandle (keep it professional)
- **Bio**: "Backend Engineer | Building scalable systems | Go • Python • Microservices"
- **Tone**: Visual, engaging, technical but accessible
- **Personality**: Creative technical, shares visually

### Content Focus
- Code snippets (beautifully formatted)
- Architecture diagrams
- Technical tips (carousel format)
- Behind-the-scenes (development process)
- Technical concepts (visual explanations)

## Content Depth & Technical Level

### Depth Level: **Low-Medium**
- **Length**: Minimal text, visual-first
- **Technical Detail**: Key concepts, accessible
- **Code Examples**: Yes, visually formatted
- **Diagrams**: Yes, primary content
- **Target Audience**: Broader tech community, visual learners

### Technical Content Guidelines
- One concept per post
- Visual explanations
- Code snippets with syntax highlighting
- Simple, clear diagrams
- Minimal text (captions can be longer)

## Visual Identity

### Image Strategy
- **Primary**: Code snippets (Carbon, Ray.so style)
- **Secondary**: Architecture diagrams, flowcharts
- **Style**: Clean, modern, technical aesthetic
- **Color Scheme**: Consistent (dark mode friendly)
- **Typography**: Code-friendly fonts

### Image Quantity
- **Per Post**: 1 image (single post) or 5-10 images (carousel)
- **Format**: Square (1080x1080px) or vertical (1080x1350px)
- **Quality**: High resolution, optimized
- **Alt Text**: Always include

### Visual Elements
- Code syntax highlighting (consistent theme)
- Architecture diagrams (Mermaid, Draw.io style)
- Consistent color palette
- Clean, readable fonts
- Minimal, professional design

## Posting Strategy

### Frequency
- **Posts per Week**: 1-2 (from your 5/week schedule)
- **Best Days**: Tuesday, Wednesday, Thursday
- **Best Times**: 11 AM - 1 PM, 5-7 PM (local time)

### Post Types

#### 1. Code Snippet Posts (Single Image)
- Beautifully formatted code
- Key concept or tip
- **Format**: Single square image
- **Text**: Brief explanation in caption

#### 2. Carousel Posts (5-10 Images)
- Step-by-step explanations
- Architecture breakdowns
- Technical concepts
- **Format**: Carousel (5-10 slides)
- **Text**: Detailed explanation in caption

#### 3. Architecture Diagram Posts
- System architecture
- Data flow
- Component interactions
- **Format**: Single or carousel
- **Text**: Architecture explanation

#### 4. Technical Tips (Carousel)
- Quick tips series
- Best practices
- Common patterns
- **Format**: Carousel (5-7 slides)
- **Text**: Tips explanation

## Carousel Structure

### Standard Carousel Template (5-10 slides)
1. **Slide 1**: Title + hook
2. **Slides 2-8**: One concept per slide
3. **Final Slide**: Summary + call to action

### Example Carousel: "Dead Letter Queues"
- **Slide 1**: Title - "Dead Letter Queues in RabbitMQ"
- **Slide 2**: Problem - "Failed jobs block queue"
- **Slide 3**: Solution - "DLQ pattern"
- **Slide 4**: Implementation - Code snippet
- **Slide 5**: Benefits - Bullet points
- **Slide 6**: Diagram - Architecture
- **Slide 7**: Summary + CTA

## Caption Strategy

### Caption Structure
1. **Hook** (1-2 lines): Attention-grabbing
2. **Explanation** (3-5 lines): Technical concept
3. **Key Points** (bullet points): 3-5 takeaways
4. **Call to Action** (1 line): Question or engagement
5. **Hashtags** (10-15): Relevant hashtags

### Example Caption
```
🚀 Dead Letter Queues in RabbitMQ

When jobs fail, they can block your queue. Dead letter queues solve this by routing failed jobs to a separate queue for analysis and reprocessing.

Key points:
✅ Failed jobs don't block main queue
✅ Enable error analysis
✅ Manual reprocessing possible
✅ Failure pattern detection

How do you handle failed jobs in your system?

#BackendEngineering #RabbitMQ #Microservices #SystemDesign #GoLang #Python #DevOps #SoftwareArchitecture #TechTips #CodeNewbie
```

✅ Use carousels for complex topics
✅ Include code snippets
