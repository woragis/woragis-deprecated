# Projects Domain - Project Management

## Overview
Comprehensive project management features and workflows.

## Key Points

### Core Project Features
- Project CRUD operations
- Project status management
- Project metrics tracking
- Project slug generation and search
- Project duplication

### Project Sub-Entities

#### Milestones
- Create, update, toggle milestones
- Bulk update milestones
- Link milestones to projects
- Track milestone completion

#### Kanban Board
- Kanban columns (create, update, reorder, delete)
- Kanban cards (create, update, move, delete)
- Board state management
- Column and card ordering

#### Dependencies
- Create and delete project dependencies
- Track project relationships
- Dependency visualization

#### Documentation
- Create and update project documentation
- Documentation sections (create, update, delete, reorder)
- Public documentation support
- Documentation visibility control

#### Technologies
- Add technologies to projects
- Bulk create/update technologies
- Technology tagging and categorization

#### File Structure
- Define project file structure
- Bulk create/update file structures
- Hierarchical file organization

#### Architecture Diagrams
- Create and manage architecture diagrams
- Diagram visualization
- Multiple diagrams per project

### Integration Points
- Translation integration (projects translatable)
- Translation enricher for automatic translations
- Project case studies support
